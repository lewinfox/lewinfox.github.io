Usage in a Markdown file: {{ }} Each entry is " | ". The PNGs live in static/img/portfolio//. Zola makes the small WebP versions at build time; clicking a screenshot opens the original. #} {% component gallery(app, shots) %}

{% endcomponent gallery %}
